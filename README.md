## 📌 Overview

This project builds a **Responsible AI Governance System** that evaluates machine learning models for:

- Fairness ⚖️  
- Bias detection 🚨  
- Deployment risk 📉  

Unlike traditional ML projects that focus only on accuracy, this system ensures models are **ethical, compliant, and safe for real-world deployment**.

---

## ⚙️ Features

- Model Training (Logistic Regression, Random Forest)  
- Bias Detection using Disparate Impact Ratio (DIR)  
- Bias Mitigation (Threshold Adjustment)  
- Risk Scoring Engine  
- Deployment Decision System (Safe / Risky)  
- Interactive Dashboard (Streamlit)  
- Automated PDF Report Generation  

---

## 🧠 System Architecture
Dataset → Preprocessing → Model Training → Bias Analysis → Risk Scoring → Decision Engine → Dashboard → Report
