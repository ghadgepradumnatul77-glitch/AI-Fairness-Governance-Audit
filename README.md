# AI Fairness & Governance Audit System

## Overview
This project evaluates whether an AI system is safe, fair, and legally deployable.
Instead of only building a predictive model, it audits bias, fairness, and governance risk before deployment.

## Key Features
- Bias detection using Disparate Impact Ratio (80% rule)
- Intersectional bias analysis (gender + race)
- Bias mitigation using reweighting
- Monitoring bias over time
- Model bias vs accuracy tradeoff
- Threshold-based prediction fairness
- Deployment readiness decision logic

## Dataset
Adult Census Income Dataset (used widely in government & academic fairness research).

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Fairness metrics

## Outcome
✔ Identified unfair bias  
✔ Applied mitigation controls  
✔ Concluded system is NOT deployment-ready without safeguards

## Learning
This project demonstrates Responsible AI, governance thinking, and ethical ML deployment.
